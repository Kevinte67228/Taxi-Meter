# 招財計程計費器 HC-1（Taxi-Meter）

一個模擬台灣計程車計費器畫面的 PWA（漸進式網路 App），可以安裝到手機桌面，像原生 App 一樣使用。

🔗 **線上使用**：https://kevinte67228.github.io/Taxi-Meter/

> 🎉 這個 App 純粹是為了好玩而做的計程計費器模擬畫面，**不是合法計費工具**，也不具備任何官方或商業用途。所有數字、折扣、記帳功能都只是娛樂性質，請勿用於實際載客收費。
>
> 製作者：凱文

## 功能一覽

- **仿真跳表面板**：通行費、營業區、計程時間、公里數、車資，畫面配色與排版比照真實計程車計費器
- **GPS 開機即調用與即時計費**：開啟 App 時即主動請求 GPS 定位並預熱訊號（面板 `◉` 顯示即時 GPS 狀態）；按「計程計時」無縫即時計算里程與車資
- **Screen Wake Lock 防螢幕休眠**：計時期間自動防止螢幕休眠，確保系統不因鎖屏而中斷 GPS 訊號
- **可自訂跳表費率**：起跳金額／里程、續程距離／加價、低速門檻與計費秒數、夜間加成、高速公路通行費，全部可在設定裡修改
- **營業區可自訂**：設定裡有下拉選單跟清單編輯，不限於真實行政區名稱，想寫什麼都可以
- **按鍵與跳錶音效**：按鍵、車資往上跳的當下都有嗶聲，可調音調／音量／音色，也能上傳自己的音效檔
- **親友折扣（好玩功能）**：可自訂按鈕名稱與折扣，按多次會疊加折扣倍率（例如打 8 折按兩次＝6.4折），並有簡單的月結記帳功能，方便親友月底一次結清
- **車隊名稱可自訂**：會同步顯示在開機畫面與列印明細抬頭
- **螢幕字級可調**：依手機螢幕尺寸自動建議縮放比例，也可手動微調
- **列印明細**：模擬收據畫面，顯示里程、車資、通行費、總計
- **離線使用**：安裝後沒有網路也能開啟；有新版本更新時會跳出提示，點一下就自動套用，不用重新安裝

## 怎麼安裝到手機桌面

1. 用手機瀏覽器（建議 Chrome）打開 https://kevinte67228.github.io/Taxi-Meter/
2. 瀏覽器選單裡選「加到主畫面」或「安裝應用程式」
3. 桌面會出現一個獨立的 App 圖示，點開就是全螢幕、橫向顯示的計費器畫面

> ⚠️ 部分機型（尤其非預設橫向的裝置）在「安裝應用程式」這個原生安裝流程上偶爾會遇到相容性問題，如果安裝後圖示點了沒反應，可以改用「加到主畫面」——功能完全一樣，差別只在會保留瀏覽器的網址列。

## 開始使用

- **空**：歸零重置，準備開始新的一趟（GPS 依然保持背景定位與預熱）
- **計程計時**：開始計費，利用開啟時已預熱好的 GPS 即時計算里程與車資
- **停**：暫停，畫面保留最後金額
- **列印**：跳出收據樣式的總覽畫面
- **高速公路**：每按一次加收一筆固定通行費
- **親友價**（可在設定關閉）：跳出親友名單讓你選擇，套用後車資即時打折

點畫面右上角的齒輪圖示可以打開設定，調整螢幕字級、跳表費率、音效、營業區、親友折扣、車隊名稱等所有項目。

## 技術細節（給想了解或修改程式碼的人）

純前端實作，沒有後端伺服器：

- `index.html`：畫面與所有邏輯（HTML/CSS/JavaScript 單一檔案）
- `manifest.json`：PWA 設定檔（圖示、名稱、顯示模式）
- `sw.js`：Service Worker，負責離線快取與「發現新版本」的更新提示機制
- `icon-192.png` / `icon-512.png`：App 圖示

所有設定（費率、音效、營業區、親友名單、記帳明細等）都存在**使用者自己手機的瀏覽器本機儲存空間**，不會上傳到任何伺服器，換手機或清除瀏覽器資料就會重置。
